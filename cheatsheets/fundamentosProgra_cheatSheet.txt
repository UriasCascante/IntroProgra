SWITCH
sirve para simplificar la anidacion de if/else, se puede crear estructura de casos.

Para Python:
No aplica habria que generar if/else/elif anidados

Para C++
switch(variable){
	case condicon 1:
		instrucciones 1;
		break;
	case condicion 2:
		instrucciones 2;
		break;
	default:  #cuando no cumle las condiciones de los casos definidos
		instrucciones;
}

Bucle do-while:
Ejecuta las instrucciones mientras la condicion se cumpla.
Primero ejecuta y luego comprueba la condicion.

Para Python no aplica

Para C++
do{
instrucciones;
}while (condicion);

Pra aplicaciones donde se necesita primero hacer una accion, 
por ejemplo la comprobacion del pin de una tarjeta en un cajero automatico

*********************************

Bucle while:
Primero conprueba y luego ejecuta

Python:
while condicion:
	instrucciones
	
Para C++
while(condicion){

}

FUNCIONES:

Creamos funciones con piezas de codigo dentro que se va a estar utilizando de forma recurrente.
Esto ayuda a simplificar y optimizar el codigo.

Como definir una funcion:

Python:
def nombreFunc(var1,var2=valorDefault):
	instrucciones
	return valor

Para llamarla ---> nombreFunc(valor1,valor2)

En C++:
tipoFunc nombreFunc(tipo var1,tipo var2){
	instrucciones;
	return valor;
}

para llamarla nombreFunc(valor1,valor2);

PUNTEROS:
varianles que en lugar de almacenar un valor, alamcenan la direccion de la memoria
donde se almacena el valor de otra variable.

Los punteros solo existen en la mayoria de los lenguajes tipados, por lo tanto en Python no aplica

En C++:
tipo*nombre_puntero;
tipo variable;
nombre_puntero = &variable;

*********************************

RECURSIVIDAD:
Una funcion recursiva es una funcion que se llama a si misma, pero cambiando los parametros cada vez.
Se utiliza para optimizar el codigo y hacerlo mucho mas eficiente.
